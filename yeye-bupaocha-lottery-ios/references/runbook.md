# iPhone 运行手册（爷爷不泡茶）

> 2026-11-03 实测环境：iPhone Mirroring 490×1074，微信已登录，小程序首次进。
> 命令里的 `$DRIVER` 用 `iphone-bootstrap.sh` 输出的 `driver`。

## 0. 自检

```bash
bash "$SKILL/scripts/iphone-bootstrap.sh"
```

期望：`ok: true`，`window: {x:1294, y:47, w:490, h:1074}`（坐标会变，以实际为准）。

## 1. 回桌面 / 打开微信

```bash
PY="$(uv tool dir)/phone-harness/bin/python"
$PY "$DRIVER" home
$PY "$DRIVER" text
```

桌面上微信图标在 Dock；也可以直接切回微信（如果它还在前台）。
本次实测微信聊天列表显示「已登录 Mac」。

## 2. 发现 → 小程序 → 最近使用

```bash
$PY "$DRIVER" longtap 发现 --duration 0.25
$PY "$DRIVER" longtap 小程序 --duration 0.25
$PY "$DRIVER" text
```

「最近使用」里应看到「爷爷不泡茶」；本次 OCR 位置约 `(1485,388)`。
优先 `longtap 爷爷不泡茶 --duration 0.3`。

如果不在最近使用：

- 在「小程序」页顶部搜索框输入 `yeye`（ASCII）；
- 或让用户在手机上把小程序加到「我的小程序」。

## 3. 隐私协议

进入后出现「温馨提示」：

- 按钮：「拒绝仅浏览」/「同意」
- 勾选项：允许必要场景使用个人信息 + 同意《隐私协议》《用户协议》
- **停**，把原文告诉用户；用户确认后再：

```bash
$PY "$DRIVER" longtap 同意 --duration 0.45
$PY "$DRIVER" text
```

如果用户选「拒绝仅浏览」，同样 `longtap`。

## 4. 百万奖池

底部 tab 的「百万奖池」要点**图标区域**，不是文字标签。`longtap 百万奖池` 会先命中
页面顶部的「瓜分百万奖池」标题，容易点错。

```bash
$PY "$SKILL/scripts/iphone.py" tap --x 1539 --y 1030
$PY "$DRIVER" text
$PY "$DRIVER" shot /tmp/yeye-pool.png
```

期望看到：`瓜分百万奖池`、`抽 10 克足金 999 金条`、按钮 **`马上抽奖`**。
iPhone 本次页面**没有显示「剩余 N 次」**；安卓版才有「剩余 1 次」。
停在按钮前，不点。

## 5. 登录

```bash
$PY "$DRIVER" longtap 我的 --duration 0.25
$PY "$DRIVER" text
```

- 已登录：昵称/等级；回「百万奖池」。
  本次实测：昵称「微信用户」、等级「初遇」、优惠券 1 张，已登录。
- 未登录：显示「登录」/「去登录」。
  **不要自动点登录页**；iPhone 镜像里它不接收合成点击。
  让用户解锁手机手动登录一次，然后重新 `state`。

## 6. 抽奖（用户确认后）

```bash
# 短点，不要长按。0.6s 长按会触发「iPhone 使用中」，本次实测踩过。
$PY "$SKILL/scripts/iphone.py" tap --x 1624 --y 612
$PY "$DRIVER" text
$PY "$DRIVER" shot /tmp/yeye-result.png
```

> Android 版按钮是「开始抽奖」，iPhone 本次是「马上抽奖」；以页面实际文案为准。
> 本次短点后进入活动页，显示 **「开始抽奖」/「剩余 0 次」**；账号没有次数，抽不了。
> 不要点「去使用」「去下单」「去喝一杯」。

## 7. 券包

```bash
$PY "$SKILL/scripts/iphone.py" tap --x 1735 --y 1057   # 我的 tab
$PY "$DRIVER" text
$PY "$SKILL/scripts/iphone.py" long-press --x 1367 --y 988 --duration 0.3  # 我的券包
$PY "$DRIVER" text
```

本次实测券包：

- 券名：全品类饮品单杯 7 折券（八周年抽奖）
- 7 折，上限 30 元，2026-11-09 23:59 到期
- 状态：1 张，按钮「去使用」
- 与安卓侧同一账号同步

停在这里，不点「去使用」。
