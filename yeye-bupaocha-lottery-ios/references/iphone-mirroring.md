# iPhone 镜像通道

底层参考：`iphone_auto` 实验项目（phone-harness + bgphone）
（`bgphone.py` + `phone-harness` 的 SkyLight 后台驱动；截图 + Vision OCR + 坐标点击）。
当前优先复用 `mika-wechat-mini-program/scripts/ios_bridge.py`；本 skill 自带
`scripts/iphone.py`/`scripts/bgphone.py` 作为兜底。

## 前置

| 项 | 要求 |
|---|---|
| 系统 | macOS，iPhone Mirroring.app 可用 |
| 手机 | 已配对、在 Mac 附近、锁屏、没人使用 |
| 工具 | `uv tool install phone-harness`（用它带 Quartz/Vision 的 Python） |
| 权限 | 屏幕录制（截图）、辅助功能（键入） |
| 驱动 | `ios_bridge.py state` 返回 `ok: true` |

```bash
bash "$SKILL/scripts/iphone-bootstrap.sh"
```

`state.ok=false` 的常见原因：

- `连接中断`：手机不在附近/没开机/最近没解锁；
- `iPhone 使用中`：真机被拿起使用，镜像立即断开；
- `正在连接` / `解锁 iPhone`：等手机锁屏、别碰。

这三种只能由人处理，不要重试到天荒地老。

## 按压时长（实测）

| 目标 | 时长 | 说明 |
|---|---|---|
| 微信原生列表 / 搜索框 / tab | 短点 | `tap` 即可 |
| 小程序 tab、普通按钮 | 0.2–0.35 s | 短点会被静默丢弃 |
| 百万奖池「马上抽奖」landing 按钮 | **短点** | 0.6 s 长按会触发「iPhone 使用中」（2026-11-03 实测） |
| 小程序表单 / 「开始抽奖」类按钮 | 先短点，没反应再 0.2–0.3 s | 不要默认 0.45–0.9 s |
| 桌面 App 图标 | 0.22 s | 超过 0.45 s 弹长按菜单 |

「点了没反应」不一定是按太短；**先短点，再逐步加长**。本次「马上抽奖」短点有效，
0.6 s 长按反而触发了镜像中断。小程序里没有统一的「必须长按」规则。

## 坐标

- OCR 的 y 可能偏 30–60pt，**不能直接拿 OCR 坐标当精确坐标**。
- 可靠做法：`shot` 拿图（图与窗口 1:1）→ 在图上量像素 → 屏幕坐标 = 窗口原点 + 图像坐标
  → 立刻点，不缓存。
- 窗口尺寸会变：实测 490×1074；也可能 342×746 / 340×741 / 231×512。
  每次动作前重新 `state`/`shot`。
- `iphone.py`/`ios_bridge.py` 的 `tap-text`/`longtap` 用的是 OCR 坐标；
  如果点不中，改用 `shot` + 手工坐标。

## 硬限制

| 限制 | 表现 | 处置 |
|---|---|---|
| **小程序「账户登录」页不接收合成点击** | 勾选、一键登录、手机号登录全无反应；同页返回键/tab 正常 | **人工闸门**：用户解锁手机手动登录一次；登录后镜像可能断开 |
| 真机被使用 | 镜像结束，显示「iPhone 使用中」 | 用户锁屏、别碰，再连接 |
| 连接中断 | 「确保 iPhone 在 Mac 附近、已开机、最近解锁过」 | 同上；锁屏 ≠ 关机 |
| 无 AX / 无 CDP | 读不到元素树，只能 OCR | 只做「看得见 + 点得到」，不做稳定选择器 |
| 中文输入 | `type_text` 可能粘成乱码 | `pbcopy` + `⌘V`；或输入 ASCII/pinyin |
| 无多点触控 | 捏合缩放不可用 | 用页面自带按钮 |
| 窗口不可改尺寸 | `set_window_frame` 报错 | 坐标按当前窗口算 |
| DRM/受保护内容 | 黑屏 | 不绕过 |

## 搜索页特别说明

本次微信搜索页是一个 WebView，输入 `yeye` 后：

- 结果区长时间空白；
- 顶部只显示「搜索网络结果」和一条 `yeye` 历史；
- 返回键 `<` 在截图 y≈133，不在 OCR 的 y≈93；
- 不要在这个页面反复点；直接回聊天列表，走「发现 → 小程序 → 最近使用」。

## 与安卓通道的分工

| | 安卓（Mika / adb） | iPhone（镜像 + OCR） |
|---|---|---|
| 读页面 | 元素树 + 文本 | 截图 OCR |
| 点 | 元素级 | 坐标 + 按压时长 |
| 稳定性 | 高 | 中，页面一变就要重算坐标 |
| 登录墙 | Mika 可一键登录 | 登录页点不动，必须人工 |
| 适合 | 整条流程 | 导航、读页、单次点击 |
