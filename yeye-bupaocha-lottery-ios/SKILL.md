# 爷爷不泡茶「瓜分百万奖池」iPhone 镜像版

> **Scope：一次性活动 skill，不是通用工具。**
> 只服务爷爷不泡茶 2026-10-29—11-04 的「瓜分百万奖池」活动。
> iPhone 镜像/OCR 只是传输层；活动事实、入口、奖池、任务和闸门都是为这一次活动写死的。
> 跑别的品牌/活动，必须重写 `references/activity-facts.md` 和流程；不要直接套用。

**本文件所在目录就是 `$SKILL`。** iPhone 镜像底层参考
本机 `iphone_auto` 实验项目（`phone-harness` + Vision OCR + 后台 SkyLight 点击）；
当前优先复用 `mika-wechat-mini-program/scripts/ios_bridge.py`。

## 铁律

1. **先跑镜像自检。** 没有窗口、手机被占用、锁屏，都不是重试能解决的。
2. **OCR 说「看到了」不算点到。** 每个动作后要重新 `text`/`shot` 复核。
3. **不可逆动作前必须停。** 隐私协议、会员登录、抽奖、领券、下单、填地址——先回报证据，等用户点头。
4. **iPhone 的小程序登录页不接收合成点击。** 勾选、一键登录、手机号登录都可能点不动；
   必须让用户解锁手机、亲手登录一次。登录后镜像可能断开，重新连。
5. **不自动做任务。** 邀请好友、下单满 5 元都是用户行为。
6. **单账号、单活动。** 不做多账号、不并发、不代抽、不保存凭证。
7. **活动窗口**：2026-10-29 10:00:00 — 2026-11-04 23:59:59；过期就停。
8. **券以券包为准。** 弹窗可能不写全；必须进「我的 → 我的券包」读券名、折扣/上限、有效期、范围。

## 第 0 步：镜像与工具链自检

```bash
bash "$SKILL/scripts/iphone-bootstrap.sh"
```

输出里看：

- `ok: true` + `window`：镜像在线，可以继续。
- `blocked_hint`：`连接中断` / `iPhone 使用中` / `正在连接` / `解锁 iPhone`——
  让用户把手机放旁边、锁屏、别碰，再点连接。
- `reason: phone_harness_missing`：`uv tool install phone-harness`，再跑
  `bash "$SKILL/scripts/repatch.sh"`（修 pyobjc 12 的 options、中文 OCR、中文 open_app）。
- `reason: ios_driver_missing`：安装 `mika-wechat-mini-program`，或用本 skill 的
  `scripts/iphone.py`（和 `bgphone.py` 同目录）。

拿到 `driver` 后，后续命令统一用：

```bash
PY="$(uv tool dir)/phone-harness/bin/python"
DRIVER=/绝对路径/ios_bridge.py
$PY "$DRIVER" state
$PY "$DRIVER" text
$PY "$DRIVER" shot /tmp/iphone.png
$PY "$DRIVER" longtap 爷爷不泡茶 --duration 0.3
```

> `ph --doctor ios` 可能误报「没有镜像窗口」；以 `ios_bridge.py state` 的窗口信息为准。

## 第 1 步：到达活动页（可逆）

### 已验证路径（2026-11-03）

```
微信 → 底部「发现」→「小程序」→「最近使用」→「爷爷不泡茶」
→ 隐私协议「温馨提示」→（同意后）底部「百万奖池」
```

不要依赖微信顶部搜索：本次实测搜索页是 `MMFTSSOSHomeWebViewUI`，输入「yeye」后
结果区一直空白，返回键也要用截图坐标才点得动。**优先走「发现 → 小程序 → 最近使用」。**

建议动作：

```bash
$PY "$DRIVER" longtap 发现 --duration 0.25
$PY "$DRIVER" longtap 小程序 --duration 0.25
$PY "$DRIVER" longtap 爷爷不泡茶 --duration 0.3
```

如果「最近使用」里没有：

- 用「搜索小程序」，输入 `yeye`（ASCII）或先 `pbcopy` 中文再 `⌘V`；
- 或者让用户在手机上把小程序添加到「我的小程序」。

### 隐私协议闸门

进入小程序后若出现「温馨提示」：

- 按钮：**「拒绝仅浏览」/「同意」**
- 勾选项：允许在必要场景下使用个人信息，并同意《隐私协议》《用户协议》
- **停下**，把按钮和协议要点告诉用户；不要自己点。
- 用户确认后再 `longtap 同意 --duration 0.45`（或拒绝），然后复核页面。

### 活动入口

进入小程序后，底部导航点 **「百万奖池」**。注意：

- `ios_bridge.py longtap 百万奖池` 会匹配到页面顶部的「瓜分百万奖池」标题，可能点错；
- 本次实测要点**底部 tab 的图标区域**，约 `(1539,1030)`（屏幕坐标，窗口 1294,47,490×1074）；
- 点中后页面标题变成「瓜分百万奖池」，按钮是 **「马上抽奖」**（安卓版是「开始抽奖」）。

```bash
PY="$(uv tool dir)/phone-harness/bin/python"
$PY "$SKILL/scripts/iphone.py" tap --x 1539 --y 1030
$PY "$DRIVER" text
```

停在 **「马上抽奖」/「开始抽奖」** 前。不要点抽奖、不要做任务、不要分享、不要下单、不要填地址。

## 第 2 步：会员登录（人工闸门）

先看「我的」：

```bash
$PY "$DRIVER" longtap 我的 --duration 0.25
$PY "$DRIVER" text
```

- 已登录：显示会员昵称/等级；回「百万奖池」看页面和按钮文案。
  本次实测 iPhone 页面**不显示「剩余 N 次」**；安卓版才显示。不要因为没有次数文案就重复点。
- 未登录：显示「登录会员尊享多重好礼」+「登录」，券包显示「去登录」。

**未登录时不要尝试自动化登录。** iPhone 镜像里小程序「账户登录」页不接收合成点击：
勾选框、一键登录、手机号登录都可能短点/长按/双击全无反应。正确做法：

1. 告诉用户：「请在 iPhone 上解锁并手动登录一次，登录页我点不动。」
2. 用户登录后，等镜像恢复（真机被使用会中断镜像）。
3. 重新 `state`，回「百万奖池」读剩余次数。

登录后首次进入通常从「剩余 0 次」变「剩余 1 次」；这不是 bug，是首次登录赠送。

## 第 3 步：抽奖（闸门）

只有同时满足才允许点：

- 页面标题是「瓜分百万奖池」/「抽 10 克足金 999 金条」；
- 时间在 2026-10-29 10:00:00 — 2026-11-04 23:59:59；
- 登录会员是本人；
- 剩余次数 > 0；
- 用户明确说「点」。

```bash
# 短点，不要长按。0.6s 长按会触发「iPhone 使用中」，本次实测踩过。
$PY "$SKILL/scripts/iphone.py" tap --x 1624 --y 612
```

> Android 版按钮是「开始抽奖」，iPhone 本次是「马上抽奖」；以页面实际文案为准。
> **「马上抽奖」是短点有效**；不要默认 0.45–0.9s 长按。
> 点完 `text` + `shot` 复核结果；不要点「去使用」「去下单」「去喝一杯」。
> 本次实测：短点后进入活动页，显示 **「开始抽奖」/「剩余 0 次」**；
> 账号没有剩余次数，抽不了。

## 第 4 步：券包核对（只读）

```bash
$PY "$DRIVER" longtap 我的 --duration 0.25
$PY "$DRIVER" longtap 我的券包 --duration 0.3
$PY "$DRIVER" text
$PY "$DRIVER" shot /tmp/coupon.png
```

读：券名、折扣/面额、优惠上限、有效期、适用范围、状态、来源。
停在券列表/券详情，不要点「去使用」。

## iPhone 操作规则

| 目标 | 时长 / 方式 |
|---|---|
| 微信原生列表、搜索框、tab | 短点或 `longtap 0.2–0.25s` |
| 小程序 tab、普通按钮 | `longtap 0.2–0.35s` |
| 百万奖池「马上抽奖」landing 按钮 | **短点**；0.6s 长按会触发「iPhone 使用中」（本次实测） |
| 小程序表单/「开始抽奖/马上抽奖」类按钮 | 先短点；没反应再 0.2–0.3s，不要默认 0.45–0.9s |
| 桌面 App 图标 | `longtap 0.22s`；超过 0.45s 弹菜单 |

- **坐标按截图算，不按 OCR。** OCR 的 y 可能偏 30–60pt，窗口尺寸会变；
  用 `shot` 量像素，屏幕坐标 = 窗口原点 + 图像坐标，立刻点，不缓存。
- **中文输入**：先 `printf '爷爷不泡茶' | pbcopy`，再 `⌘V`；`type_text` 可能粘成乱码。
- **返回键**：搜索页左上角 `<` 在截图 y≈133（屏幕 y≈180），不是 OCR 的 y≈93。
- **窗口尺寸**：实测 490×1074；也可能变成 342×746/340×741/231×512。每次重新 `state`。
- **不要多点触控**：捏合不可用。
- **DRM/受保护内容**会黑屏。

## 失败处置

| 现象 | 处置 |
|---|---|
| `state` 没有窗口 | 打开 iPhone Mirroring、解锁手机、保持窗口可见 |
| `iPhone 使用中` / 连接中断 | 用户锁屏、别碰手机；重新连接。点抽奖后出现此提示，先查券包确认是否已抽，不要重复点 |
| 小程序搜索空白 | 改走「发现 → 小程序 → 最近使用」 |
| 隐私协议弹窗 | 停下，用户选「拒绝仅浏览 / 同意」 |
| 登录页点不动 | **正常**；让用户解锁手机手动登录一次 |
| 剩余 0 次 | 不抽；报告任务（邀请/下单），等用户决定 |
| 抽奖按钮无反应 | 加长到 0.6–0.9s；仍无反应就 `shot` 核对坐标 |
| 券包为空 | 先看登录态；未登录时为空不代表没中奖 |
| 活动已结束 | 停；窗口 11-04 23:59:59 |

## 交付格式

1. **结果原文**：券名、折扣/面额、上限、有效期、适用范围、来源。
2. **当前状态**：剩余次数、是否还能再抽、券是否到账。
3. **下一步建议**：别点「去使用」除非用户要下单；任务是否值得做由用户判断。
